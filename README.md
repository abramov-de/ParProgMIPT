# ParProgMIPT
#### Parallel programming course in MIPT (3rd year, 2024).


### Как подключиться к серверу (кластеру):

для этого пишем в терминале:

`ssh свойлогин@remote.vdi.mipt.ru -p 52960`,

после чего вводим пароль.

Попадаем в свою директорию. 
Можем посмотреть, что тут есть при помощи команды `dir`.
Пока там пусто.

### Создаем необходимые файлы

Для создания файла вводим `touch название_программы.c`.
Копируем сюда код из соответствующего задания.
Сохраняем (`Ctrl + S`) и выходим.

Для редактирования файлов можно пользоваться командой `mcedit название_файла.расширение`
или `vim название_файла.расширение`. Можно вместо этого пользоваться VScode.

Далее создаем `.sh` файл, как мы делали это ранее для `.c`:
`touch название_программы.sh`
Сюда вписываем следующий код (будет прикреплен в виде файла):
```shell
#!/bin/bash
#PBS -l walltime=00:01:00,nodes=1:ppn=3
#PBS -N ваше_название_(будет_отображатся_в_очереди)
#PBS -q batch
cd $PBS_O_WORKDIR
mpirun --hostfile $PBS_NODEFILE -np 3 ./ваша_программа.exe
```
Сохраняем и выходим.

Теперь сделаем `.exe` файл из `.c` файла.
Для этого пишем команду
`mpicc ваша_программа.c -o ваша_программа.exe`

После этого, при вводе команды `dir` должно отображаться три файла:
`.c`, `.sh` и `.exe`.

### Отправим программу в очередь.

Для этого пишем команду `qsub ваша_программа.sh`.
Должно написать что-то типа `193324.head.vdi.mipt.ru`.
Далее пишем `qstat`. Должны увидеть таблицу очередей, в которой указано наше обозначение из файла `.sh`.
Для проверки правильности выполнения откроем файл:
`vim ваше_обозначение_из_таблицы.o193324` (цифры будут другие).
В нем долдно быть 3 раза `Hello, World!` и данные `commsize, my_rank`.
